# Pramoda Home Foods — Version 2

## Included
- Responsive premium website
- Logo placeholder at `assets/pramoda-logo.png`
- Daily menu controlled from `menu-data.js`
- Online order form → WhatsApp
- Pickup location + Google Maps
- Three contact numbers
- Service timings
- Free GitHub Pages-ready structure

## Before publishing
1. Put your actual Pramoda logo at `assets/pramoda-logo.png`.
2. Open `site-config.js` and replace `ADD YOUR EXACT PICKUP ADDRESS HERE`.
3. Replace `mapsUrl` with your exact Google Maps share/search URL if needed.
4. Update daily menu and prices in `menu-data.js`.

## Free publishing
Upload the whole folder to a GitHub repository and enable GitHub Pages from Settings → Pages → Deploy from branch → main → root.

## Daily menu update
Edit only `menu-data.js`, save it, and upload/commit the changed file. The website will show the new menu automatically.
